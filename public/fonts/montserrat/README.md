# Montserrat estática

Fuente: https://github.com/JulietaUla/Montserrat/tree/master/fonts/ttf

Archivos oficiales estáticos convertidos de TTF a WOFF2 con FontTools, sin cambiar contornos ni métricas. Cada archivo contiene un peso real (300–900), sin ejes variables. Licencia SIL OFL en OFL.txt.

Se usan para evitar que un navegador renderice todos los pesos con el valor base Thin de la fuente variable. El sitio conserva Montserrat y sus pesos tipográficos.

Subconjunto latino y latino extendido, con signos, acentos españoles y símbolos habituales. Se conservan las métricas y las funciones OpenType de los glifos incluidos; otros alfabetos usan la fuente de respaldo.
